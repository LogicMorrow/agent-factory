# about-me-patterns.md — patterny "O mnie" 2026

Good / bad / ugly examples sekcji "O mnie" dla portfolio PL. Konsumowany przez `portfolio-content-writer` (E6) jako reference + operator manualnie.

## GOOD patterns

### Pattern G1: "Co + Dlaczego + Wartość" (3 akapity)

```
[Akapit 1: Co robię, konkretnie, 30-50 słów]

[Akapit 2: Dlaczego ta hybryda kompetencji, krótka historia, 30-50 słów]

[Akapit 3: Wartość dla pracodawcy/klienta, 20-40 słów]
```

**Przykład:**

> Buduję agenty AI dla sprzedaży B2B, projektuję analytics dashboards i piszę cold maile, które konwertują. Pracuję na styku trzech światów: kodu, danych i komunikacji z klientem.
>
> Zacząłem od sprzedaży B2B w branży tech (3 lata), potem doszły dane (Python, SQL, pandas), a w 2024 wciągnęła mnie inżynieria AI — Claude API, Anthropic SDK, agenty autonomous. Hybryda powstała organicznie, bo każdy projekt potrzebował wszystkich tych obszarów naraz.
>
> Jeśli budujesz B2B SaaS lub potrzebujesz automatyzacji procesów sprzedaży i analytics, dostajesz jedną osobę zamiast trzech. Mniej koordynacji, więcej kontekstu między obszarami.

### Pattern G2: "Specjalizacja + Niche claim"

```
Jestem [tytuł zawodowy] specjalizującym się w [konkretna nisza].

[2-3 zdania: dlaczego ta nisza, jakie projekty robię, dla kogo]

[1-2 zdania: konkretny outcome który dostarczam]
```

**Przykład:**

> Jestem AI engineerem specjalizującym się w autonomous agents dla B2B SaaS.
>
> Przez 3 lata pracowałem w sprzedaży B2B, w 2024 zacząłem budować agentów Claude Code dla automatyzacji powtarzalnych workflow. Pracuję głównie z SaaS Series A-C, gdzie zespoły sprzedaży/CS chcą skalować bez liniowego wzrostu headcount.
>
> Konkretnie: zbudowałem agenta cold mailing który podniósł CTR z 8% do 19% (200 maili/dzień, pełna automatyka + HITL gate).

### Pattern G3: "Lista 3 rzeczy + osobowość"

```
3 rzeczy, które robię najlepiej:

1. [Rzecz 1 — konkret]
2. [Rzecz 2 — konkret]
3. [Rzecz 3 — konkret]

[1-2 zdania osobowość / quirk / why]
```

**Przykład:**

> 3 rzeczy, które robię najlepiej:
>
> 1. **Cold mailing pipelines z AI personalization** — od scrape do A/B test
> 2. **Analytics dashboards dla SaaS** — Python + Metabase, 0 do production w 2 tyg
> 3. **Agenci Claude Code dla automatyzacji** — autonomous workflow + HITL gates
>
> Lubię projekty, gdzie kod, dane i kontakt z klientem łączą się w jeden problem. Mniej refactoru, więcej dostarczania wartości.

### Pattern G4: "Origin story" (storytelling)

```
[1 zdanie hook: surprising fact lub origin moment]

[2-3 zdania: jak doszło do current state]

[1 zdanie: co teraz, na czym fokus]
```

**Przykład:**

> Sprzedałem swoją pierwszą umowę B2B w 2021, sam dzwoniąc do klientów z laptopa w studio na 12m².
>
> Po roku robiłem 30+ deals/mies, ale brakowało mi danych — które kanały działają, które prospekty są worth follow-up. Nauczyłem się Pythona, SQL, BI. Potem AI — Claude Code, agenty, autonomous workflows.
>
> Teraz buduję narzędzia, które robią to, co kiedyś robiłem manualnie — żeby zespoły sprzedażowe mogły skalować bez liniowego wzrostu headcount.

## BAD patterns

### Pattern B1: Corporate buzzword salad

```
Dynamiczny, kreatywny pasjonat z bogatym doświadczeniem w obszarze transformacji cyfrowej i innowacji technologicznych. Łączę kompetencje analityczne, sprzedażowe i programistyczne, podejmując ambitne wyzwania na styku biznesu i technologii. Otwarty na nowe projekty i nieustannie się rozwijam.
```

**Dlaczego ŹLE:**
- 100% buzzwords, 0% konkretu
- "Dynamiczny, kreatywny" — wszyscy to piszą
- "Bogate doświadczenie" — ile? Gdzie? Jakie?
- "Transformacja cyfrowa" — generic, brak focus
- "Otwarty na nowe projekty" — i co z tego? Konkret jakich projektów
- Mogła to napisać AI w 2 sek

### Pattern B2: Lista wszystkiego co znasz

```
Skills: Python, JavaScript, TypeScript, React, Vue, Angular, Next.js, Nuxt, SvelteKit, Node.js, Express, FastAPI, Django, Flask, PostgreSQL, MySQL, MongoDB, Redis, AWS, GCP, Azure, Docker, Kubernetes, Terraform, GitHub Actions, CircleCI, Jenkins, Jest, Vitest, Cypress, Playwright, Tailwind, Sass, Less, Figma, Sketch, Adobe XD...
```

**Dlaczego ŹLE:**
- "Jack of all trades, master of none" sygnał
- Recruiter nie wie w czym jesteś *naprawdę* dobry
- Zniknęło "kim jesteś" — jest tylko inwentarz
- 80% z tej listy to rzeczy, których tknąłeś raz w bootcamp

**Lepiej:** Top 3-5 + kontekst per technology.

### Pattern B3: "Po polsku ale myślę po angielsku"

```
Jestem passionate o building scalable solutions w obszarze B2B SaaS. Mam expertise w AI engineering i sprzedaży, i love delivering value dla klientów. Otwarty na collaboration z teams które values innovation.
```

**Dlaczego ŹLE:**
- Code-switching = lazy + brakuje voice
- "Passionate", "expertise", "love delivering value" — kalki EN
- Jeśli PL portfolio → pisz PL. Anglicyzmy w technical terms ok ("cold mailing", "agent AI"), ale nie w pozostałych słowach.

### Pattern B4: "Self-deprecating" overdose

```
Hmm, no nie wiem co tu pisać. Robię trochę różnych rzeczy, sam jeszcze nie do końca wiem czy jestem dobry w czymś konkretnym. Trochę programuję, trochę z danymi pracuję, sprzedaż też mi szła. Jak coś — pisz.
```

**Dlaczego ŹLE:**
- Brak confidence = brak trust
- Recruiter/klient nie zatrudnia osoby która sama nie wie kim jest
- Hybryda kompetencji = atut, ale prezentowane jako atut, NIE jako "trochę różnych rzeczy"

**Lepiej:** Pattern G1 (Co + Dlaczego + Wartość).

## UGLY patterns (NIGDY)

### Pattern U1: Wymyślony "imponujący" tytuł

```
Senior Lead AI Architect | Chief Innovation Officer | Strategic Sales Hybrid Expert
```

**Dlaczego ŹLE:**
- "Senior Lead Chief" — title inflation = red flag
- Recruiter widzi w 2 sek że to puffery
- Wystarczy: "AI engineer · analityk · B2B sales" (3 obszary, NIE 3 tytuły)

### Pattern U2: Plagiat z LinkedIn

```
Results-driven professional with 5+ years of experience in cross-functional collaboration...
```

**Dlaczego ŹLE:**
- 50% LinkedIn ma identyczną intro
- EN w PL portfolio = zero personality
- Recruiter widział to 500 razy

### Pattern U3: Lista certyfikatów bez kontekstu

```
Certyfikaty: AWS Certified, GCP Professional, Coursera ML, edX Python, Udemy Master Class...
```

**Dlaczego ŹLE:**
- Cert ≠ kompetencja
- "Coursera ML" = każdy może kliknąć i kupić
- Wystarczyłoby: 1 cert który *naprawdę* znaczy + projekt który *pokazuje* tę wiedzę

### Pattern U4: Polityczne / kontrowersyjne deklaracje

```
Wspieram [partia X] i wartości [ideologia Y]...
```

**Dlaczego ŹLE:**
- Eliminujesz 50% potential klientów/pracodawców
- Portfolio = professional, nie political
- Jeśli polityka jest istotna → osobny site/blog

## Voice checklist (operator-specific)

Przed publish "O mnie" sprawdź:

- [ ] Czy używam "ja" (active voice)? NIE passive ("zostało zbudowane")
- [ ] Czy każde 2-3 zdania ma konkretną liczbę / nazwę / use case?
- [ ] Czy unikam: "passionate", "dynamiczny", "kreatywny", "synergii"?
- [ ] Czy zdania ≤ 20 słów średnio?
- [ ] Czy jest 1 osobisty quirk lub origin story moment?
- [ ] Czy outcome > inwentarz tech?
- [ ] Czy wypełniam Pattern G1/G2/G3/G4 (NIE B1/B2)?
- [ ] Czy polish-typography lint PASS (`/proofread-pl`)?
