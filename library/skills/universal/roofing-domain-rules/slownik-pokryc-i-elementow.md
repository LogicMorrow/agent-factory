# Słownik pokryć dachowych i elementów dekarskich — PL

Nazwy, krótkie opisy i terminologia pozycji kosztorysowych dla ofert dekarskich. Scope: pokrycia dachowe + obróbki blacharskie + orynnowanie + okna dachowe. NIE zawiera technologii montażu ani norm PN-EN.

---

## 1. Pokrycia dachowe — słownik nazw

| Nazwa pozycji kosztorysowej | Synonimy / warianty nazwy | Uwagi dla dekarza |
|---|---|---|
| **Blachodachówka** | blacha dachówkopodobna, blacha trapezowa profilowana | Najpopularniejsze pokrycie w PL (cena/jakość). Różni producenci = różne profile. |
| **Blacha trapezowa** | trapez, blacha fałdowa | Płaska z fałdami trapezowymi. Często na budynkach gospodarczych i halach. |
| **Blacha na rąbek stojący** | blacha na rąbek, rąbek stojący, blacha płasko-rąbkowa | Połączenie przez rąbki zamiast nakładkowego. Estetyczna, droga. Tytan-cynk, miedź, stal powlekana. |
| **Dachówka ceramiczna** | dachówka, karpiówka (jeśli kształt), dachówka z gliny | Klasyczna, ciężka (ok. 40-50 kg/m²). Wymaga mocniejszej więźby. |
| **Dachówka betonowa** | dachówka cementowa | Tańsza niż ceramiczna, podobna waga. |
| **Gont bitumiczny** | gont, shingles, papa gontkowa | Lekkie pokrycie z bitumicznych pasków. Dachy o małym kącie nachylenia min. 12°. |
| **Gont drewniany** | gont cedrowy, dach z gontu | Rzadkie w PL — tradycyjne, estetyczne, drogie. |
| **Papa termozgrzewalna** | papa zgrzewalna, membrana bitumiczna, papa bitumiczna | Dachy płaskie lub o bardzo małym nachyleniu. Zgrzewana palnikiem. |
| **Membrana EPDM** | membrana dachowa, folia EPDM | Dachy płaskie, tarasy. Guma kauczukowa — trwałość 30-50 lat. |
| **Folia wstępnego krycia** | FWK, membrana dachowa wstępna, papa podkładowa | NIE pokrycie docelowe — warstwa pod właściwe pokrycie, zapobiega kondensacji. |

### Pozycja w ofercie (jak zapisywać)

W ofercie dekarskiej pokrycie to jedna pozycja kosztorysowa:

```
Pokrycie dachu — blachodachówka [pow. połaci]  →  kwota ryczałtowa
```

Metraż połaci to metryka pomocnicza do kalkulacji — w ofercie ryczałtowej pojawia się informacyjnie (nie mnożnik). Szczegóły w `quotation-pl-rules`.

## 2. Obróbki dekarskie blacharskie — słownik

Obróbki to blacharskie elementy uszczelniające i wykańczające — osobna pozycja kosztorysowa.

| Element | Opis techniczny | Użycie |
|---|---|---|
| **Gąsior** | Element wzdłuż kalenicy — zamyka szczyt dachu, chroni przed deszczem i ptakami | Każdy dach dwuspadowy na kalenicy |
| **Wiatrownica** | Listwa blachy na bocznej krawędzi połaci (przy szczycie) — prowadzi wodę z dachu | Dachy bez rynny szczytowej |
| **Kosz** | Wklęsła obróbka w miejscu spotkania dwóch połaci dachowych — odprowadza wodę | Dachy z narożem wklęsłym (koszem) |
| **Okuć komina / okóć komina** | Obróbka blacharska dookoła komina — uszczelnia styk komina z połacią | Każdy komin przechodzący przez dach |
| **Pas nadrynnowy** | Blacha na okapie, prowadząca wodę do rynny | Pod każdą rynną przy okapie |
| **Pas pod-okapowy** | Blacha lub listwa między murem a deską okapową | Uszczelnienie okapu od spodu |
| **Obróbka okna dachowego** | Kołnierz uszczelniający okno Velux/Fakro — może być z blachy lub kompletny (od producenta okna) | Przy każdym oknie połaciowym |
| **Obróbka komina murowanego** | Okapniki i fartuch z blachy dookoła komina | Kominy murowane — szersze obróbki niż systemowe |

### Pozycja w ofercie

```
Montaż obróbek dekarskich blacharskich  →  kwota ryczałtowa
```

Zawiera: gąsiory + wiatrownice + kosze + okuć kominów + pasy + kołnierze okien (jeśli w zakresie). Jedna pozycja zbiorcza — nie rozbijaj per element w ofercie ryczałtowej.

## 3. Okuć komina / okóć komina

Szczególna pozycja — <operator> używa formy **okóć** (nie okuć). Obie formy zaakceptuj, w dokumentach firmy <firma> używaj formy z karty projektu (`[do weryfikacji u <operator>a]`).

**Co to jest:** Blacharska obróbka miejsca, gdzie komin przechodzi przez połać dachu. Składa się z kilku elementów:
- **Fartuch tylny** — za kominem (od strony kalenicy), odprowadza wodę
- **Fartuch przedni** — przed kominem (od strony okapu), uszczelnia
- **Fartuch boczny** — po bokach komina
- **Kieszeń odpływowa** — zbiera wodę spływającą za kominem

W wykazie pozycji oferty: `Montaż okuć komina` lub `Montaż okóć komina` + liczba kominów.

**Pozycja metryczna pomocnicza:** `Liczba okuć kominów` (szt.) — wpływa na kalkulację kwoty.

## 4. Okna dachowe — słownik

| Nazwa | Opis | Uwagi dla dekarza |
|---|---|---|
| **Okno dachowe** | Ogólna nazwa okna montowanego w połaci dachu | Terminy Velux / Fakro to marki, nie typy |
| **Okno połaciowe** | Synonim okna dachowego — okno w płaszczyźnie połaci | Najczęstsza forma: skrzydło otwierane uchylnie lub obrotowe |
| **Okno wyłazowe** | Okno z podestem umożliwiającym wyjście na dach | Dla serwisu dachu i komina |
| **Świetlik dachowy** | Okno stałe (nieotwieralne) wpuszczające światło | Płaskie dachy lub bardzo małe kąty |
| **Okno mansardowe** | Pionowe okno w ścianie mansardowej (nie w połaci) | Inny montaż niż połaciowe |
| **Kołnierz uszczelniający** | Kompletny zestaw obróbki okna — od producenta (np. Velux EDW) lub blacha na miejscu | Zawsze wymagany przy montażu |

### Pozycja w ofercie

```
Montaż okien dachowych  →  kwota ryczałtowa
Liczba okien dachowych: [N szt.]  (metryka pomocnicza)
```

Cena okna (dostawa) i cena montażu to dwie różne kwestie — w ofercie ryczałtowej zazwyczaj jedna linia „montaż + obróbka". Okno może dostarczyć klient — pole edytowalne.

## 5. Orynnowanie — słownik

| Element | Opis | Typowy materiał w PL |
|---|---|---|
| **Rynna** | Poziomy rynielik przy okapie zbierający wodę z dachu | Stal powlekana, PVC, tytan-cynk, miedź |
| **Rura spustowa** | Pionowa rura odprowadzająca wodę z rynny do gruntu lub kanalizacji | Jak rynna — ten sam system materiałowy |
| **Hak rynnowy** | Uchwyt mocujący rynnę do deski okapowej | Stal nierdzewna lub ocynkowana |
| **Złączka rynny** | Mufa łącząca dwa odcinki rynny | Wbudowana lub nakładana |
| **Narożnik rynny** | Element gięty na narożniku budynku | Zewnętrzny i wewnętrzny |
| **Lej rynnowy / lejek** | Połączenie rynny z rurą spustową | Część systemu |
| **Kolano rury spustowej** | Zakrzywienie rury (zmiana kierunku) | Zazwyczaj 45° lub 72° |
| **Obejma rury spustowej** | Uchwyt mocujący rurę do ściany | Co ~1 m wysokości |
| **Osłona rury spustowej** | Plastikowa ochrona dolnej części rury (anty-wandal) | Opcjonalna |

### Systemy rynnowe popularne w PL

- **PVC** — najtańszy, popularny na domach jednorodzinnych. Marki: Galeco, Nicoll, Gamrat.
- **Stal powlekana** — trwalszy, estetyczny. Marki: Ruukki, Budmat, ICOPAL (Rannila).
- **Aluminium** — lekki, nierdzewny. Droższy od stali.
- **Tytan-cynk** — ekskluzywny, trwałość 60-80 lat. Szary mat. Do dachów wysokiej klasy.
- **Miedź** — premium, patynuje na zielono. Najdroższy.

### Pozycja w ofercie

```
Orynnowanie  →  kwota ryczałtowa
```

Jeden element oferty dekarskiej, obejmujący rynny + rury spustowe + uchwyty + łączniki. W metrykach pomocniczych: mb rynny / ilość rur spustowych.

## 6. Słownik terminów oferty dekarskiej — pozycje kosztorysowe

Standardowe pozycje kosztorysowe w ofercie ryczałtowej <operator>a:

| Pozycja | Opis zakresu |
|---|---|
| Pokrycie + więźba | Kompletna więźba (drewno + montaż) + pokrycie dachowe (materiał + montaż) lub tylko montaż jeśli klient dostarcza materiał |
| Orynnowanie | System rynnowy: rynny + rury spustowe + uchwyty + łączniki (dostawa + montaż lub sam montaż) |
| Montaż okien dachowych | Wstawienie okna połaciowego + obróbka kołnierzem (materiał okna: klient lub dekarz) |
| Montaż obróbek dekarskich | Blacharskie: gąsiory + wiatrownice + kosze + okuć kominów + pasy nadrynnowe |
| Montaż okuć / okóć komina | Wyodrębniona pozycja gdy wiele kominów lub duże obróbki kominów (alternatywnie wchodzi w „obróbki") |
| Z ręki (custom) | Dowolna pozycja: np. „naprawa istniejącej więźby" / „impregnacja drewna" / „termomodernizacja okapu" |
